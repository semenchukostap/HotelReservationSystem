# HotelReservationSystem.Web

This is the ASP.NET Core MVC web application for the Hotel Reservation System.

## Configuration Files

- `appsettings.json` - Main application settings
- `appsettings.Development.json` - Development environment settings

The application settings include:

1. ConnectionStrings - Database connection information
2. Logging configuration with appropriate levels
3. Authentication settings for external providers
4. Application-specific settings migrated from Web.config
